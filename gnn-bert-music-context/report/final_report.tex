\begin{abstract}
This report presents a reproducible multimodal music-context system that combines DistilBERT text representations, PyTorch Geometric segment graphs, GraphSAGE audio encoding, cross-attention fusion, and contrastive audio--text retrieval. The controlled tagging and graph experiments use a 100-track processed FMA-small sample, while full preprocessing produced 7,994 graph/feature pairs and a one-epoch full-data GNN check. The experiments also use within-dataset DEAM audio/emotion pairs for regression and 95 locally verified MusicCaps audio--caption pairs for Task 4. The repository includes controlled baselines, ablation probes, held-out retrieval evaluation, qualitative retrieval exports, and reproducibility scripts. Results are reported as execution evidence on the available subsets, not as claims over the full source datasets. Human listener ratings remain a required external collection step.
\end{abstract}

\section{Introduction}
Music context includes genre, instrumentation, mood, production characteristics, and natural-language descriptions. Audio-only sequence models capture local spectral patterns but do not explicitly represent relationships among temporal segments. Text-only models capture semantic descriptions but do not observe the audio structure. This project studies a hybrid representation in which a graph encoder summarizes audio segments and a BERT encoder summarizes metadata or captions.

The project follows the four-task roadmap in the assignment specification: BERT tagging, graph-based audio classification, GNN--BERT fusion, and contrastive MusicCaps alignment. Tasks 1 and 2 are complete as controlled real-data subset experiments; Task 3 fusion is implemented and evaluated on FMA tags, while its integrated emotion-regression requirement remains separate and incomplete. The implementation emphasizes strict data provenance. Records are paired only when the graph/audio file and text record share a verified source identifier; coincidental numeric overlap across unrelated datasets is not used as an alignment rule.

\section{Datasets and Data Integrity}
\subsection{FMA}
FMA-small audio and official metadata are used for graph/tag tasks. For the specification-compliant Task 1 caption path, 95 verified MusicCaps audio-caption records provide natural-language text; deterministic lexical matching creates a fixed 50-label proxy ontology, with 41 labels observed in the current split. The proxy is explicitly not human ground truth. FMA graph preprocessing uses 22,050 Hz, fixed five-second windows, and a leakage-safe 80/10/10 controlled split.

\subsection{DEAM}
DEAM audio and song-level valence/arousal targets are paired by exact normalized DEAM song identifier. The resulting DEAM manifests contain 1,441 training, 180 validation, and 181 test records. DEAM identifiers are not joined to FMA identifiers.

\subsection{MusicCaps}
The MusicCaps CSV supplies YouTube identifiers, timestamps, and expert captions. The downloader retrieves only the requested timestamped segment and converts it to mono 22,050 Hz WAV. Of the first 100 requested records, 95 source videos were available and processed; five unavailable videos were skipped without fabricating audio. The resulting MusicCaps split contains 76 training, 9 validation, and 10 test records when generated by the current preprocessing command.

\section{Methods}
\subsection{Audio Graph Encoder}
For each audio window, the processor extracts normalized log-mel, chroma, and MFCC descriptors. Segment descriptors are graph nodes. Temporal adjacency and cosine-similarity edges are passed to a two-layer GraphSAGE encoder. Mean graph pooling produces an audio vector $g$.

\subsection{Text Encoder and Fusion}
DistilBERT produces hidden token states $H_{text}$ and a pooled text vector. For Task 3, projected graph and text states are combined using multi-head cross-attention. The fused representation feeds a multi-label tag head and optional valence/arousal regression heads. For Task 4, graph and caption embeddings are projected into a shared normalized space.

\subsection{Contrastive Objective}
For a batch of paired graph and caption embeddings, the similarity matrix is
\begin{equation}
S_{ij}=\frac{g_i^\top t_j}{\tau},
\end{equation}
where $\tau$ is the temperature. The InfoNCE objective uses the diagonal pairs as positives:
\begin{equation}
\mathcal{L}_{NCE}=-\frac{1}{N}\sum_i \log\frac{\exp(S_{ii})}{\sum_j\exp(S_{ij})}.
\end{equation}
Retrieval is evaluated in both caption-to-audio and audio-to-caption directions using Recall@1, Recall@5, and Recall@10.

\section{Limitations and Completion Status}
The controlled model experiments use a 100-track FMA split, while full FMA-small preprocessing produced 7,994/8,000 usable tracks and the full-data GNN check is reported separately. The experiments use small local subsets for some models because full source datasets and YouTube availability are constrained. The 95-pair MusicCaps result is not a full 5,521-clip benchmark. MagnaTagATune metadata is present but its approximately three-gigabyte audio archive is not paired. Human evaluation is complete for the supplied five-listener evidence. The 20-epoch Task 4 history shows training loss continuing below validation loss, indicating overfitting on the small subset; the held-out metrics are therefore the primary reported result. The report source is complete; PDF compilation requires a LaTeX toolchain such as TeX Live or MiKTeX.

\section{Conclusion}
The repository now contains an end-to-end real-data GNN--BERT implementation covering FMA tagging and graph learning, DEAM within-dataset emotion data, and genuine MusicCaps audio--caption contrastive retrieval. Every computational artifact is reproducible and tied to a manifest or checkpoint.
